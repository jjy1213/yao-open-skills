# 纳瓦尔宝典 Skill

用《纳瓦尔宝典》的专长、杠杆、判断力与幸福观，分析职业选择、服务产品化、长期合作和目标取舍。结合用户的事实与限制，给出判断、出处、行动和改判条件。

[English](README.en.md) · [详细使用指南](../../docs/skills/yao-naval-almanack-skill.md) · [技能入口](SKILL.md)

## 可以用来做什么

- 从工作记录中找出可复用的成果、重复消耗和下一步行动。
- 比较工作机会、转行方向、能力组合与长期积累。
- 将重复的客户交付拆成可复用模块，评估质量、维护成本和成果归属。
- 检查长期合作的行为证据、责任范围和激励。
- 梳理注意力、收入、自由、家庭时间和比较压力之间的取舍。
- 解释书中概念、做章节导读、核验引文或整理阅读路线。

## 安装与使用

下载或克隆本仓库，将整个 `skills/yao-naval-almanack-skill/` 文件夹放到 AI 客户端支持的技能目录，按客户端要求启用并重新加载。保留 `references/` 和 `agents/`，使知识与调用规则一同安装。

使用 Skills CLI 安装到 Codex 的当前项目：

```bash
npx skills add yaojingang/yao-open-skills --skill yao-naval-almanack-skill --agent codex
```

显式调用：

```text
使用 $yao-naval-almanack-skill，分析这份工作记录。
请找出可复用的成果、最主要的重复消耗，以及下周值得试的一项调整。
```

自然提问：

```text
客户报告有很多重复流程，怎样提高交付效率并积累可复用的成果？
```

描述包含职业、产品化、合作与目标取舍等自然问题，客户端可以按意图选用技能。实际调用取决于客户端的技能加载、启用状态和选择机制。用户要求本次停用时，尊重该要求。

## 会得到什么

回答通常包括主要判断、相关原则与来源、小范围行动，以及会改变建议的新事实。概念解释和出处查询按用户问题作答；简短问题保留简短回答。

例如，在“每周花八小时做相似客户报告”的虚构情境下，可以先比较两次真实交付的重复步骤，试做一个小模块，记录工时、质量和返工量。客户差异或维护成本较高时，缩小复用范围。这里的行动属于情境应用，书中观点另附来源。

## 内容与来源

版本 **0.2.0** 包含 36 个正文小节的原创中文知识卡、前言与附录索引、28 个应用场景、72 条触发边界案例和五个构造示例。来源基准为 Eric Jorgenson 编排的官方英文原书，完整阅读入口见 [原书官网](https://www.navalmanack.com/)。

知识卡采用原创转述，并分别标记书内观点、官方扩展和应用设计。逐字引文需要回查原始材料。中文出版版本的译文和页码需要按版本核对。

无需额外账号、连接器或运行脚本。原话核验与动态事实查证需要客户端具备可用的搜索或阅读能力。

## 边界与许可

纯润色、计算、代码、泛化规划和只顺带提及纳瓦尔的请求按各自任务处理。具体投资交易与临床诊疗交由对应能力；实际建议保留现实约束与可核验依据。

公开目录包含技能指令、原创转述与来源链接。用户材料、工作日志、原书 PDF、抓取档案和运行输出留在各自授权范围内。
