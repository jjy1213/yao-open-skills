中文知识卡为基于英文材料的原创转述。页码对应这份官方英文 PDF 的书内页码，不作为中文出版版本页码。逐字中文译文、中文版本差异及有声版专属对话未取得完整校对证据。原书和逐页网页材料保留在研究档案；安装包提供提炼、定位与链接。

## 来源层级

1. 书内观点：知识卡的“含义”为中文转述，包含编者组织后的内容。
2. 官方扩展：X01 至 X07，明确标记未收入正文。
3. 应用设计：知识卡中的“适用与局限”“误解”“应用”“问自己”、场景流程、示例、小实验与边界检查为本 skill 的设计与提示；实际核验另有来源时单独注明，避免将提示归为书中要求。
4. 原话核验：实际读取原始访谈、文章或贴文后才报告已核验。书中转引保留原作者；无法找到原始材料时保留疑点。

书内观点不能统一推断为纳瓦尔原创。引用金额、时薪、收益和个人作息时保留个人经验与历史背景；当前事实需要另行验证。未来增补材料记录新来源与日期，避免悄悄改变原书范围。

## 使用与维护

在支持 Agent Skills 的客户端加载 `SKILL.md`；可以显式使用 `$yao-naval-almanack-skill`，并描述问题、事实、目标和限制。无需账户、附加服务或运行脚本。查证原话、其他作者观点和最新事实时需要可用的搜索或阅读能力。

保持 `SKILL.md` 精简。新增问题先复用已有原则；改变触发边界时更新 [触发案例](trigger-cases.md)，并用五个标准输出示例检查。包内不保存私密用户记录、凭据或未经验证的动态事实。
