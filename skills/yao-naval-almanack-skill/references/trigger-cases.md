# 72 条触发案例

这些条目是预期路由与验收样本。它们本身不代表已在真实客户端执行或证明了自动路由准确率。修改描述后，用客户端或模型评估器只提供描述、请求和必要上下文；先保存判断，再与预期核对，避免把答案直接交给评估器。

## 判定顺序

1. 看用户当前要求完成什么任务。
2. 理解、核验或应用纳瓦尔思想时使用；相关职业、产品化、长期合作、注意力与目标取舍的实质建议也可使用，无须提及人名。
3. 看具体任务与必要上下文，单个主题词不足以触发；普通金融数学、纯润色与通用规划保留原路由。
4. 名字用于图片、排版、翻译或引用背景时，按实际任务路由。
5. 临床诊断、治疗与具体投资交易由对应能力处理。解释书中观点仍可使用本 skill。
6. 混合任务分配各部分职责，保留已授权范围；解释观点由本 skill 负责，写作和外部动作由对应能力处理。
7. 尊重明确停用、本次仅做格式处理或指定其他框架单独分析的要求；上一轮启用不意味着跨任务继续启用。
